# AtlasDesk 知识库问答测试输出结果

## 1. AtlasDesk 生产环境应如何完成一次安全部署？

回答：先确认最近一次备份成功且校验通过，再拉取并校验镜像签名；数据库先执行 `./atlasctl migrate --mode=expand`，随后启动新容器。`/health/ready` 连续 3 次返回 200 后才能切流，切流后继续观察错误率和延迟 30 分钟，最后再执行 contract 迁移。

来源：

- `03-production-deployment.md`，章节“关键事实”和“操作流程”（第 13～25 行）

## 2. 当前 Access Token 的默认有效期和签名算法是什么？

回答：当前 Access Token 默认有效期为 15 分钟，使用 RS256 签名。文档提到的 30 分钟是 2024 年旧配置，已经废弃。

来源：

- `05-access-token.md`，章节“关键事实”和“易混淆点与限制”（第 13～16、26～27 行）

## 3. 成员目录的正常查询结果和空结果分别缓存多久？

回答：成员目录正常查询结果缓存 5 分钟，也就是 300 秒；空结果使用 30 秒的负缓存。

来源：

- `29-directory-search.md`，章节“关键事实”（第 13～16 行）

## 4. API 进程与 Worker 进程的默认数据库连接池上限分别是多少？

回答：API 进程的默认数据库连接池上限是 40，Worker 进程是 20；这两个上限均按单个进程计算，不是整个集群的总数。

来源：

- `13-database.md`，章节“关键事实”和“易混淆点与限制”（第 13～16、26～27 行）

## 5. 生产数据库全量备份保留多久，如何证明备份确实可恢复？

回答：每日数据库全量备份保留 35 天。备份任务成功本身不能证明可恢复，还需要每季度至少在隔离环境完成一次恢复演练，并记录恢复点、耗时、缺口和清理结果。

来源：

- `15-backup-retention.md`，章节“关键事实”“操作流程”和“易混淆点与限制”（第 13～27 行）

## 6. AtlasDesk 支持哪些用户认证方式？登录成功后令牌如何续期并防止重放？

回答：AtlasDesk 的终端用户可以使用本地账号密码登录，也可以使用企业 OIDC 单点登录。OIDC 使用 Authorization Code Flow，并要求 PKCE S256。认证成功后签发 Access Token 和 Refresh Token；刷新时执行 Refresh Token rotation，旧令牌成功使用后立即失效。如果检测到旧 Refresh Token 被重放，系统会撤销整个 token family。

来源：

- `04-authentication-overview.md`，章节“适用范围”和“关键事实”（第 9～16 行）
- `07-oidc-sso.md`，章节“适用范围”和“关键事实”（第 9～16 行）
- `06-refresh-token.md`，章节“关键事实”和“操作流程”（第 13～22 行）

## 7. API 5xx 持续升高时，什么条件会触发严重告警，告警随后如何到达并升级给值班人员？

回答：当 API 5xx 比例连续 5 分钟超过 2% 时触发严重告警。指标进入 Prometheus，满足持续窗口的规则发送到 Alertmanager；严重告警随后路由到 PagerDuty 和 `#incident-critical`。PagerDuty 先呼叫主值班，5 分钟未确认则升级到备值班。

来源：

- `23-monitoring.md`，章节“关键事实”和“操作流程”（第 13～23 行）
- `24-alerting.md`，章节“关键事实”和“操作流程”（第 13～22 行）

## 8. 请区分用户资料缓存、成员目录查询缓存、目录空结果缓存和静态资源缓存的 TTL。

回答：用户资料缓存默认 20 分钟；成员目录正常查询结果缓存 5 分钟，即 300 秒；目录空结果负缓存 30 秒；带内容哈希的静态资源缓存 86400 秒。四个 TTL 对应不同对象，不能互换。

来源：

- `11-redis-cache.md`，章节“关键事实”（第 13～16 行）
- `29-directory-search.md`，章节“关键事实”和“易混淆点与限制”（第 13～14、26～27 行）
- `12-edge-cache.md`，章节“关键事实”和“易混淆点与限制”（第 13～15、25～26 行）
