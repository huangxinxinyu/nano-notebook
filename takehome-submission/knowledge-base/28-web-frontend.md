# Web 前端运行约定

- 文档状态：现行
- 维护团队：Web 平台组
- 项目：AtlasDesk

## 适用范围

Web 客户端使用 React 和 TypeScript，通过 HTTPS 调用 /v1 API。

## 关键事实

- 浏览器不持久化保存 Access Token。
- CSRF 防护使用 SameSite Cookie 与请求令牌组合。
- 前端资源使用内容哈希文件名。
- 用户可见错误展示稳定错误码和 request_id。

## 操作流程

1. 页面启动时加载当前会话。
2. 接口失败按错误类型决定重试或提示。
3. 收到未授权响应时只执行一次刷新协商。

## 易混淆点与限制

- 前端状态不是权限权威。
- 静态资源 TTL 见边缘缓存文档。
