# 测试知识库生成 Prompt

本次考试使用 AI 辅助设计了一个名为 AtlasDesk 的虚构企业协作项目知识库。主要 Prompt 如下：

> 请生成一套 30～50 个 Markdown/TXT 文件组成的虚构软件项目知识库，总文本目标为 3～10 万字。项目名为 AtlasDesk，覆盖架构、生产部署、认证、Access Token、Refresh Token、OIDC、缓存、数据库、备份、API、安全、监控、告警、日志、故障恢复和用户指南。
>
> 材料必须刻意包含以下复杂度：部分文档有相似背景；同一完整答案分布在多个文件；部分事实重复；存在容易混淆但对象不同的 TTL；存在明确标注为历史或已废弃的旧方案；至少准备两个知识库中完全不存在答案的问题。现行专题文档必须能够覆盖正确答案，历史说明只能作为干扰项。
>
> 同时设计至少 5 个单文档问题、2 个跨文档问题、1 个相似信息区分问题和 2 个知识库不存在答案的问题。每个有答案的问题给出期望事实和期望来源，但不要把答案写进问题文本。

为了保证可复现性，最终没有直接保存随机生成结果，而是把审核后的事实和模板固化在 `generate.py` 中。执行以下命令可重新生成完全相同的材料：

```bash
python3 knowledge-base/generate.py
```

生成器不会联网，也不会读取任何真实项目配置或凭据。
