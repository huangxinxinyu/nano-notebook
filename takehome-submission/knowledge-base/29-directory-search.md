# 成员目录搜索

- 文档状态：现行
- 维护团队：搜索平台组
- 项目：AtlasDesk

## 适用范围

成员目录搜索从 PostgreSQL 权威数据构建轻量索引，并对常见查询使用 Redis 缓存。

## 关键事实

- 目录查询结果缓存 5 分钟，即 300 秒。
- 空结果负缓存 30 秒。
- 搜索最多返回 100 条成员记录。
- 成员权限变化后发布失效事件。

## 操作流程

1. 规范化查询中的空格和大小写。
2. 按 tenant_id 限定候选成员。
3. 缓存未命中时查询索引并回填。

## 易混淆点与限制

- 用户资料详情缓存 20 分钟，不是目录查询结果 TTL。
- 空结果的 30 秒也不是查询结果的正常 TTL。
