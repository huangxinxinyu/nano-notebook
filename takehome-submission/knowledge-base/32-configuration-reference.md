# 配置参考

- 文档状态：现行
- 维护团队：平台工程组
- 项目：AtlasDesk

## 适用范围

配置分为非敏感环境变量、Secret reference 和数据库动态配置。

## 关键事实

- ATLAS_HTTP_PORT 默认 8080。
- ATLAS_DB_POOL_MAX 默认 40，仅用于 API 进程。
- ATLAS_REDIS_PROFILE_TTL 默认 20m。
- ATLAS_DIRECTORY_CACHE_TTL 默认 5m。

## 操作流程

1. 复制 config/example.env。
2. 填写非敏感地址和 Secret reference。
3. 运行 atlasctl config validate。
4. 启动时记录配置摘要而不是 Secret 值。

## 易混淆点与限制

- 环境变量名称相似时必须核对具体缓存对象。
- 生产不得使用 example.env 中的占位凭据。
