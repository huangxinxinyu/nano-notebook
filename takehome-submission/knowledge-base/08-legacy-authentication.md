# 历史认证方案说明

- 文档状态：已废弃
- 维护团队：身份平台组
- 项目：AtlasDesk

## 适用范围

本文保留 2024 年认证方案，供排查旧客户端，不代表当前配置。

## 关键事实

- 旧版 Access Token 有效期为 30 分钟。
- 旧版 Refresh Token 有效期为 14 天。
- 旧版内部工具曾接受静态 API Key。
- 这些参数在 2025.3 版本后全部停止签发。

## 操作流程

1. 发现旧客户端时记录版本和租户。
2. 要求客户端升级并重新登录。
3. 确认新会话使用 15 分钟 Access Token 和 30 天 Refresh Token。
