# 企业 OIDC 单点登录

- 文档状态：现行
- 维护团队：身份平台组
- 项目：AtlasDesk

## 适用范围

企业租户可以配置一个 OIDC 身份提供方，并通过 Authorization Code Flow 登录。

## 关键事实

- 必须使用 PKCE S256。
- 回调地址必须精确匹配控制台登记值。
- 系统校验 issuer、audience、state 和 nonce。
- 默认以 email claim 匹配成员，也可以配置不可变 subject 映射。

## 操作流程

1. 管理员录入 issuer、client_id 和加密后的 client_secret。
2. 系统读取 discovery document 并验证 JWKS。
3. 测试登录成功后才能启用该身份源。

## 易混淆点与限制

- 不接受隐式流程返回的 access_token。
- 身份提供方的组信息只有经过显式映射才会转成 AtlasDesk 角色。
