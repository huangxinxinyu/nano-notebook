# 监控指标与服务目标

- 文档状态：现行
- 维护团队：可靠性工程组
- 项目：AtlasDesk

## 适用范围

监控覆盖请求、数据库、缓存、队列和业务流程，并使用统一 request_id 与 trace_id 关联。

## 关键事实

- API 可用性月度目标为 99.9%。
- API p95 延迟目标低于 400 毫秒。
- 5xx 比例连续 5 分钟超过 2% 触发严重告警。
- Worker 最老任务等待时间超过 120 秒触发告警。

## 操作流程

1. 指标先进入 Prometheus。
2. 告警规则在满足持续窗口后发送到 Alertmanager。
3. Alertmanager 路由到值班系统并创建事件。
4. 值班人员按运行手册确认影响范围。

## 易混淆点与限制

- 单个瞬时尖峰不会立即呼叫值班人员。
- SLO 是服务目标，不是每个请求的硬保证。
