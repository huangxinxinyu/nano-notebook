# 生产部署手册

- 文档状态：现行
- 维护团队：平台工程组
- 项目：AtlasDesk

## 适用范围

生产发布使用 Docker Compose 运行经过签名的镜像，部署过程包含备份、迁移、健康检查和流量切换。

## 关键事实

- 最低要求为 Docker 26、Compose v2.27、4 核 CPU、16 GiB 内存和 100 GiB 可用磁盘。
- 发布命令是 docker compose -f deploy/compose.prod.yaml up -d。
- 数据库迁移命令是 ./atlasctl migrate --mode=expand。
- 健康门禁要求 /health/ready 连续 3 次返回 200。
- 默认回滚窗口为新版本切流后的 30 分钟。

## 操作流程

1. 确认备份任务最近一次成功且校验通过。
2. 拉取并校验镜像签名。
3. 先执行 expand 迁移，再启动新容器。
4. 等待三个健康采样全部通过后切换流量。
5. 观察错误率和延迟 30 分钟，再执行 contract 迁移。

## 易混淆点与限制

- 不得先执行破坏性 contract 迁移。
- 开发环境的 docker compose up 不能作为生产发布命令。
- 回滚应用版本时不得回滚已提交的用户数据。
