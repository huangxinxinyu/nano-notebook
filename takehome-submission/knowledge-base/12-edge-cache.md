# 边缘静态资源缓存

- 文档状态：现行
- 维护团队：Web 平台组
- 项目：AtlasDesk

## 适用范围

CDN 缓存带内容哈希的 JavaScript、CSS、字体和公开图片。

## 关键事实

- 带内容哈希的静态资源 Cache-Control max-age 为 86400 秒。
- HTML 入口页 max-age 为 60 秒。
- 认证后的 API 响应不得进入共享 CDN 缓存。

## 操作流程

1. 构建阶段生成内容哈希文件名。
2. 发布新版本后先上传静态资源，再切换 HTML。
3. 紧急回滚时恢复上一版 HTML 引用。

## 易混淆点与限制

- 86400 秒只适用于不可变静态资源。
- 该 TTL 与 Redis 用户资料缓存和目录查询缓存无关。
