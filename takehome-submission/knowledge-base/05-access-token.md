# Access Token

- 文档状态：现行
- 维护团队：身份平台组
- 项目：AtlasDesk

## 适用范围

Access Token 是调用 AtlasDesk API 的短期 Bearer 凭证。

## 关键事实

- Access Token 默认有效期为 15 分钟。
- 令牌使用 RS256 签名，并包含 tenant_id、subject、roles 和 expires_at。
- API 节点只接受当前或仍在轮换宽限期内的签名密钥。
- 权限变更不会延长已经签发令牌的生命周期。

## 操作流程

1. 客户端把令牌放在 Authorization: Bearer 请求头。
2. 收到 401 token_expired 后使用 Refresh Token 换取新令牌。
3. 服务端校验签名、受众、签发方、过期时间和租户。

## 易混淆点与限制

- 2024 年旧版本曾使用 30 分钟有效期，该配置已经废弃。
- 不得把 Access Token 写入 URL、日志或前端持久化存储。
